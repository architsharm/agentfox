## Direction contract

THESIS: The page sells authority over agent actions, not a filter. It refuses the category default of a feature grid under a hero: the story moves from vision, to the moment of action, to the five things you control, to proof.
OWN-WORLD: Existing AgentFox world, raised: white ground, ink type in Archivo display / Plex body, one crimson accent used only for the action under check, hairline rules instead of pill eyebrows and boxed cards, the line-art gate canvas as the visual signature.
STORY: Agents act; you stay in control. Prompt checks miss the moment that matters, the tool call. AgentFox finds, governs, protects, tests and proves every agent. Peer-reviewed numbers back it. Start in one command.
FIRST VIEWPORT: Gate canvas behind; centred vision line "Agents act. You stay in control." in display ink at statement size, then the unchanged H1, lead, two buttons, fine print with release link; works-with strip at the fold.
FORM: established-world raise, no roll. seed: none (pinned) The user kept the incumbent world in their own words: "Take references and update ours because I believe that we are in a much better space" (2026-11-20). Copy pins: "Agents act. You stay in control."; "Vision above, tagline kept".
SIGNATURE: the "moment of action" timeline: a crimson line draws down through four stations as it scrolls into view (customer asks, agent reads a web page, agent calls send_email with an address from that page, AgentFox holds it for a person). Motion grammar: one draw, ease-out, reduced-motion shows the finished state.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
